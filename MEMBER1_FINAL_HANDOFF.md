## Canonical Demo
The canonical scenario flows as follows, deterministically generated by Member 1:
1. **NORMAL**: Request for "Where is order #8271?" triggers `get_order`, results in `SUCCESS`, no retry loops.
2. **FAILURE**: Request with config `agent_version="*-fail-timeout"` triggers a simulated connection timeout loop causing repeated execution evidence (`latency_ms` accumulating, 4 failure tool events).
3. **FIXED**: Request with config `agent_version="*-fix-timeout"` and `retry_limit=2` successfully bounds the retry loop and returns a graceful fallback message.

## Integration Boundary
